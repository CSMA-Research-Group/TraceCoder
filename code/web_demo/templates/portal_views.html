开始使用

还没有模型接口，可以做什么？

在总览或示例库启动四个预设响应演示，查看执行轨迹、逐轮计划、代码差异和评审包。也可创建项目、保存需求与固定测试版本，待模型配置后运行。

如何使用官方示例和业务代码？

官方示例可直接载入“生成与修复”。已有失败代码请选择“修复已有失败代码”。测试支持顶层 assert、unittest 和 check(candidate)。当前范围是单文件 Python，尚不支持自动检出和修改整个仓库。

“完成”和“修复成功”有什么区别？

完成表示流程正常结束。只有有效、非空的固定测试集合全部通过，才表示通过该测试集。达到轮数预算、停滞上限、跳过测试或执行超时均不会被计为全部通过。

怎样接入团队研发与 CI？

保存带来源标识的任务版本，通过 API 或随包 CI 脚本提交，获取测试结果、候选补丁和证据。由团队评审后应用改动；实例面向同一信任域，公开演示模式仅开放固定案例。

哪些来自官方，哪些作了工程调整？

保留官方 Flask 页面结构、三个核心提示词正文与 12 个示例。执行器、队列、持久化与界面按部署需求整合；历史与回滚行为按论文修正。详细来源、提交与文件哈希见代码包 provenance/UPSTREAM.json。
